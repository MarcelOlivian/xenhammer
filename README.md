# X E N - H A M M E R
A web-based alternative for the classic Hammer editor for GoldSrc

## Motivation
Since tool-making is much simpler these days, I wonder if I can streamline some old hobbies which necessitated complex setups on the personal PC. One of those old hobbies was Half-Life mapping and honestly I'd like to be able to access the editor from whatever computing device I have at hand.
